# Imagine Moore Naming Map

Interactive naming-opportunities map for Bishop Moore Catholic's Center for the Arts campaign.
Demo built by Aaron Peabody (BMC '14) from public information on bishopmoore.org. Not an official Bishop Moore page.

- `index.html` is the source page. All spaces, prices, and statuses live in the `SPACES` array near the bottom.
- `assets/` holds the floor plans and renderings published on the campaign page.
- `./build.sh` writes the standalone page to `docs/`, which GitHub Pages serves.
